# Plataforma Única - Sistema de Conciliação Financeira

Sistema de conciliação financeira para gestão de pagamentos, mapas de liquidação e distribuição proporcional.

[![Deployed on Vercel](https://img.shields.io/badge/Deployed%20on-Vercel-black?style=for-the-badge&logo=vercel)](https://vercel.com/thiagovespas-projects/v0-financial-platform-interface)

## Funcionalidades

- **Conciliador Inteligente**: Conciliação automática e manual de pagamentos recebidos com mapas de liquidação
- **Distribuidor Proporcional**: Distribuição proporcional de valores entre credores
- **Administração**: Gestão de pagadores, credores e mapas de liquidação

## Tecnologias

- Next.js 15
- React 19
- TypeScript
- Tailwind CSS
- shadcn/ui
